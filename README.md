# LVD SCADA Dashboard — Demonstrator

**Lake Victoria to Dodoma Water Supply Project, Tanzania**
Web-based SCADA monitoring dashboard built for Ministry of Water (MoW) stakeholder presentations.

---

## IMPORTANT: Demonstrator Scope

- **Simulated data only.** No live plant connection. All values are generated by a physics-based simulator.
- **Read-only.** All control widgets are visually present but disabled ("Control disabled in demonstration mode").
- **No real control commands are issued.**

---

## How to Run

```bash
cd lvd-scada
npm install
npm run dev
```

Open **http://localhost:5173** in Chrome. No internet required after npm install.

---

## Screens

| Screen | Description |
|---|---|
| **Route Overview** | GIS map — 600 km Mbalika → UDOM corridor. Click any site for live faceplate. |
| **Hydraulic Profile** | Long-section elevation vs. chainage with hydraulic grade line and live values. |
| **Water Balance** | Flow waterfall, NRW tracker, per-offtake billing volumes (DUWASA/SUWASA/KASHWASA). |
| **Alarms & Events** | Filterable alarm list with acknowledge workflow (site/priority/unacked filters). |
| **Trends** | Multi-tag trend viewer with CSV export and canned report buttons. |
| **Energy** | Per-station kW, kWh/m³ efficiency, TANESCO tariff cost estimate. |
| **Cybersecurity** | IT/OT segmentation diagram, IEC 62443 controls checklist. |

## Scenario Injection (for live demo)

Click **"Inject Scenario"** (bottom-right, any screen):

| Scenario | Effect |
|---|---|
| **Pump Trip** | P1 trips — standby auto-starts, vibration alarms fire across IBPS stations |
| **Pipe Burst** | Sudden pressure drop on gravity main |
| **Comms Fail** | Sibiti IBPS-1 goes to COMMS FAIL state |
| **Turbidity Spike** | Raw water NTU excursion at Mbalika Intake |

Scenarios auto-clear after ~2 minutes. Click "Clear scenario" to cancel early.

## Architecture

```
data/
  sites.json              # 22-site asset register
  tag-templates.json      # Instrument template per node class
src/
  simulator/              # Physics-based data simulator (5 s tick)
  context/                # React context + state reducer
  components/faceplates/  # 5 faceplate components (IBPS, Reservoir, Intake, WTP, Offtake)
  screens/                # 7 screens
```

Tags are generated programmatically from `sites.json × tag-templates.json`. Swap the simulator for a real OPC UA / MQTT bridge by replacing the adapter in `src/simulator/simulator.ts`.

## 10-Minute Demo Walkthrough

1. **0:00** — Route Overview. 600 km corridor, 5 node classes, Mbalika Intake → UDOM.
2. **1:30** — Click **Sibiti IBPS-1**. IBPS faceplate: flow, pump curve with live operating point, VFD, energy.
3. **3:00** — **Hydraulic Profile**. Elevation long-section, hydraulic grade line, live values at each node.
4. **4:30** — **Water Balance**. Abstraction → WTP → offtakes → UDOM. NRW %. Billing table per offtake.
5. **6:00** — **Energy**. 81 MW total, kWh/m³, TANESCO tariff modes.
6. **7:00** — Inject **Pump Trip** scenario. Go to **Alarms & Events** — CRITICAL alarm, acknowledge workflow.
7. **8:30** — **Cybersecurity**. IT/OT segmentation, dual firewall, VPN-only, IEC 62443.
8. **9:30** — Toggle **Phase 2 (2068)**. Show capacity uplifts. Wrap up.
